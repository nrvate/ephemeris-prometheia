# Traditional star names beyond the IAU Catalog of Star Names (docs/STARS.md).
#
# One object per line: KEY: NAME, NAME, ...
#   KEY is a Bayer designation with the catalog's abbreviations ("bet1 Sco",
#   "alp Cen"), a Flamsteed one ("80 UMa"), "HR n", "HIP n" or "M n".
#   NAMEs are alternates to the IAU name (which the generator adds itself).
#   A name belongs to one object only: names Allen gives to several stars
#   (Scheat for delta Aqr as well as beta Peg, Deneb for several "tails")
#   stay with the star that SIMBAD and the IAU give them to.
# Every name must occur in R. H. Allen, Star-Names and Their Meanings (1899):
# tools/gen/gen_star_catalog.py looks for it in the book's OCR text and
# refuses a name it cannot find. The OCR is damaged, so a name of 6-10
# letters may differ from the text by one letter and a longer one by two;
# names of 5 letters or fewer must match exactly. The generator prints the
# passage each name matched. Common modern spellings of Allen's names are
# used.
